Static instances of the site's Google Fonts, for image generation (`src/app/opengraph-image.tsx`),
which can't use web fonts. Cut from the variable fonts in github.com/google/fonts with
fontTools' instancer. Both are SIL Open Font License 1.1 (licences alongside).

- `BricolageGrotesque-ExtraBold.ttf`: wght 800, wdth 100, opsz 72
- `Figtree-SemiBold.ttf`: wght 600
