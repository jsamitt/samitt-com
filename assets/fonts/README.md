Static instances of the site's Google Fonts, for generated images, which can't use web fonts. Nothing uses them since #50 made the
link-preview card a static PNG; they stay for any generated card later (case studies). Cut from the variable fonts in github.com/google/fonts with
fontTools' instancer. Both are SIL Open Font License 1.1 (licences alongside).

- `BricolageGrotesque-ExtraBold.ttf`: wght 800, wdth 100, opsz 72
- `Figtree-SemiBold.ttf`: wght 600
