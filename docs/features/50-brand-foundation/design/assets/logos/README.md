Outlined SVG wordmarks (no font required). Inks are fixed: `-ink` files are `ink` (#14302B) letters for page, surface and band; `-on-dark` files are `on-dark` (#F1F4EE) letters for the ink section only. The disc is always `accent` (marigold). Use `proof-wordmark-*` day to day (nav 32px, footer 24px tall) and `proof-software-lockup-*` for formal contexts. Minimum height 20px; clear space equal to the disc on all sides.
